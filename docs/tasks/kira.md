## KF1. Ошибки API — понятным текстом

`client.ts` на любой ответ не-2xx пишет «Сервер вернул ошибку N». API отвечает `{"error": {"code", "message", "field"}}` с русским текстом («Накоплено не может быть больше суммы цели», «Дата в формате ГГГГ-ММ-ДД», «Слишком много вопросов подряд. Подождите минуту.»). Показывать `error.message`, если он есть; для 401 — вернуть на вход.

## KF2. Импорт: номер строки файла (#36) и несуществующие даты (#52)

- Присылать в каждой строке `row` — номер строки в файле (заголовок — строка 1). Сервер вернёт его в `rejected[].row` и в «Строка N: …» предупреждений — номера совпадут с ошибками разбора на фронте.
- В `csvRowSchema` проверять, что дата существует (`2026-02-30` → ошибка разбора). Сервер такую строку тоже отклонит, но пользователь увидит ошибку раньше — в предпросмотре.
