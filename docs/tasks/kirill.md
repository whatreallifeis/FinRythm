## K3. Telegram-бот · Ч3–5:30

Структура:
```
bot/
├── __main__.py      запуск: python -m bot (long polling)
├── config.py        TELEGRAM_BOT_TOKEN, API_BASE_URL, BOT_API_SECRET, MINI_APP_URL
├── api_client.py    httpx.AsyncClient; заголовки X-Bot-Secret, X-Telegram-User-Id; таймаут 40 с
├── handlers.py      команды и текст
├── formatting.py    деньги «9 800 ₽», даты «10 октября», сборка сообщений
└── texts.py         все тексты бота
```
- `/start`: приветствие (кто ты и чем помогаешь, 2–3 предложения), плашка **«Демо-режим. Данные вымышлены. Не является финансовой рекомендацией»**, inline-кнопки «Демо: стипендия + подработки (P1)», «Демо: уже в дефиците (P2)», «Демо: фрилансер (P3)»; кнопка «Открыть приложение» (`WebAppInfo(url=MINI_APP_URL)`) — только если `MINI_APP_URL` задан.
- Кнопка демо → `POST /api/profile/demo/p1` → сообщение «Загружен профиль …» + сразу сводка как `/limit`.
- `/limit` → `GET /api/summary`: крупно лимит в день и сколько дней до поступления; формула (`formula_text`); допущения списком; при `deficit` — «Не хватает N ₽» и что можно сделать; при `insufficient_data` — что заполнить; внизу `origin.label`.
- `/spend` → топ-5 категорий с долями и суммами (текстовые «полоски» `▇▇▇▇▁▁` для наглядности), регулярные платежи, крупные траты.
- `/risks` → список рисков с иконками по severity (ℹ️ ⚠️ ❗).
- `/goal` → цели: нужный взнос в день, когда достигнешь при текущем темпе.
- Любой текст → `POST /api/chat`: сначала сообщение «Считаю…» (редактируется ответом), затем `answer`, источники ссылками, дисклеймер мелко. `refused` — ответ без изменений.
- Документ `.csv` в чат (S) → `POST /api/transactions/import?mode=append` → отчёт импорта.
- Ошибки API: 503 → «AI сейчас недоступен, но /limit и /spend работают»; сеть → «Сервер недоступен, попробуйте через минуту».
- Разрабатывай против API на заглушках (V1 от Вероники выходит к Ч2). Локально: `uvicorn` в одном терминале, `python -m bot` в другом.
- Тесты `bot/tests/` (в `backend/tests` не клади): форматирование денег и дат, сборка сообщений по `SummaryResponse` из P1–P3 (без сети).
