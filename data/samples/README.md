# Примеры входных данных

Синтетические выписки студента для экрана «Данные» (загрузка CSV). Реальных данных нет. Номер карты
`2200 1234 5678 9012` вымышленный.

Формат, который разбирает фронтенд (`frontend/src/shared/lib/csv.ts` в ветке `front`):

```
date,amount,category,merchant
2026-09-01,-12000,rent,Аренда комнаты
2026-09-20,"-1 250,50",food,Супермаркет
```

- **Разделитель.** Только запятая. Сумму с пробелами и запятой берите в кавычки.
- **`date`.** Формат `ГГГГ-ММ-ДД`.
- **`amount`.** Минус — расход, плюс — доход.
- **`category`.** Одна из `food`, `transport`, `subscriptions`, `entertainment`, `health`, `education`,
  `rent`, `other`. Незнакомая категория превращается в `other`.

Ожидаемые результаты ниже — для даты расчёта 26.09.2026 (`APP_TODAY` на стенде).

## `transactions_errors.csv` — ошибки по строкам

| Строка файла | Что не так | Кто отклоняет |
|---|---|---|
| 2 | — корректная | загружается |
| 3 | пустая сумма | фронтенд: «сумма должна быть числом» |
| 4 | текст «сто» вместо суммы | фронтенд: «сумма должна быть числом» |
| 5 | дата `21.09.2026` | фронтенд: «дата должна быть в формате ГГГГ-ММ-ДД» |
| 6 | сумма 0 | фронтенд: «сумма не может быть нулевой» |
| 7 | дата в будущем (15.10.2026) | сервер: «Дата операции в будущем» |
| 8, 9 | дубликат (та же дата, сумма, магазин) | сервер: строка 9 пропущена с предупреждением |
| 10 | номер карты в описании | сервер: «Похоже на номер карты. Такие данные загружать нельзя.» |
| 11 | незнакомая категория «кафе» | загружается как `other` |
| 12 | пустое описание | фронтенд: «не указано описание операции» |

Итог: 3 операции загружены (строки 2, 8, 11), 5 строк отсеял фронтенд, 2 — сервер, 1 дубликат пропущен.

Номера строк в ответе сервера сейчас считаются по присланному списку, а не по файлу (issue #36).
